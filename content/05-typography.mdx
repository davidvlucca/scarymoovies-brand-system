# Typography

Type is atmosphere. On ScaryMoovies, every headline that makes a viewer lean forward and every body line they read in low light is shaped by one typeface doing two jobs — and doing both without compromise.

---

## Font Families

### Primary & Display — Inter

**Inter** is the only typeface on ScaryMoovies. It carries every word — from the 88px hero title to 12px timestamp metadata. That is not a simplification; it is a deliberate decision. Inter at weight 900 in ALL CAPS is a deadpan horror statement. It does not distress, it does not dramatise, it just holds. At body weight it is the most legible screen sans available. The darkness lives in the content and the colour, not in the typeface.

The display role uses Inter Black (900) set uppercase. The body and UI role uses Inter Regular–SemiBold (400–700). The pairing is the same family at opposite ends of the weight axis.

Use Inter for: hero banners, section titles, navigation labels, buttons, form inputs, metadata strings (runtime, year, rating), badge text, captions, and every interactive element.

**Google Fonts / Next.js loading:**

```tsx
// app/layout.tsx
import { Inter, JetBrains_Mono } from 'next/font/google';

const inter = Inter({
  subsets: ['latin'],
  variable: '--font-body',
  display: 'swap',
  weight: ['400', '500', '600', '700', '800', '900'],
});
```

**CSS custom property:** `--font-body` (body) / `--font-display` (aliases body — same family)
**Fallback stack:** `system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif`

## Font Weights

ScaryMoovies uses a controlled weight palette. Using fewer weights keeps the visual hierarchy intentional and prevents visual noise on dark surfaces.

| Weight | Value | When to Use |
|---|---|---|
| Regular | 400 | All body text, descriptions, general prose |
| Medium | 500 | Subtle emphasis within body, label text, nav items at rest |
| SemiBold | 600 | Heading-md and heading-sm, active nav states, button labels |
| Bold | 700 | Heading-xl and heading-lg, strong emphasis, display-lg |
| ExtraBold | 800 | Strong marketing callouts where Black is too heavy |
| Black | 900 | All display-* steps set uppercase — section titles, hero banners, tier letters |

Avoid using weights below 400 in the product UI. Thin weights on dark backgrounds fail contrast checks and feel anaemic against the mood of the platform.

## Line Height and Letter Spacing

Display text needs compressed tracking so large letterforms feel architectural rather than scattered. Body text needs generous leading to stay readable in low-light viewing contexts.

| Category | Line Height | Letter Spacing | Notes |
|---|---|---|---|
| `display-2xl` / `display-xl` | 1.05 | −0.03em | Near-solid leading; Inter Black condenses naturally at 900 |
| `display-lg` | 1.1 | −0.025em | Slight breathing room added |
| `heading-xl` / `heading-lg` | 1.2 | −0.02em | Tight but not cramped; Inter handles this cleanly |
| `heading-md` / `heading-sm` | 1.3 | −0.01em | Comfortable for multi-line card titles |
| `body-lg` / `body-md` | 1.6 | 0em | Relaxed leading improves readability at 16px–18px |
| `body-sm` | 1.5 | 0.01em | Slightly opened tracking at small sizes aids legibility |
| `label` | 1.2 | 0.08em | All-caps labels require wide tracking to read correctly |

**Rule of thumb:** as size increases, tighten letter spacing. As size decreases, open it.

---

## Usage Rules

These rules are non-negotiable across all surfaces — product screens, marketing pages, email templates, and component documentation.

**Display text is Inter Black, set uppercase.** `display-lg` and above use weight 900 with negative tracking. Never set display text at weights below 700. Never mix a display step with sentence case — all-caps is part of the specification, not optional styling.

**Inter handles everything.** Navigation, buttons, form labels, metadata, body copy, tooltips, captions — Inter at the appropriate weight. One typeface family, zero font-switching complexity, zero serif/sans collisions.

**Emphasis inside body uses weight, not a different face.** Stressed words inside a body paragraph get `font-weight: 600`. Do not introduce a second family for emphasis.

**JetBrains Mono** (`--font-mono`) is the third member of the stack. Use it for: film runtime, release year strings, timestamp metadata, code samples in the brand system, and empty-state instructional text in the tier list. It signals "data" rather than "copy."

## Accessibility

**Minimum body text size is 14px (`body-sm`).** No informational text in the product may render below this threshold. The `label` token at 12px is permitted only for decorative tags and badges where the same information is available elsewhere in context (for example, a genre tag on a card that also displays the genre in the title).

**Display text at weight 900** is an even-stroke sans at large sizes — no thin hairlines to lose. Still: do not reduce opacity of display type below 90%. At small sizes the heavier strokes can bleed, so never use display weights below `display-lg` (48px).

**Letter spacing and all-caps labels:** the `label` token requires `letter-spacing: 0.08em` whenever text is rendered in uppercase. All-caps text without wide tracking fails WCAG SC 1.4.12 (Text Spacing) in practice even when it technically passes.

**Font loading:** Inter and JetBrains Mono are loaded via `next/font/google` with `display: swap`. System fallbacks are visible immediately — no invisible text flash. Next.js applies `adjustFontFallback: true` by default to minimise layout shift.

:root {
  /* Font families — injected by next/font; fallbacks below */

  --text-display-xl: 3.75rem;

  --text-body-lg: 1.125rem;

  --tracking-label: 0.08em;
}
